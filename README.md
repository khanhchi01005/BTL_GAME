# T-Rex Game (Mini Project)

---

## Introduction

The T-Rex Game is a simple project inspired by the offline dinosaur game (Chrome Dino). The player controls a dinosaur to jump over obstacles and score points. The goal of the project is to implement the game logic, sound effects, and animation to create a smooth gameplay experience.

## Expected Score Range

- Target score: 8 – 8.5

## Features

- Menu: Displays “New Game”, “Help”, “Exit”, and options when the game is over.
- Sound: Background music in the menu, gameplay music, and sound effects for jumping and collisions.
- Sound toggle button to enable/disable audio in the game.
- Obstacles appear continuously; their speed and spawn frequency increase based on the score.
- Saves and displays the highest score.

## Justification for Expected Score

- Most of the game was self-implemented (movement logic, collision detection, scoring).
- Applied knowledge of audio, animation, and timing functions (e.g., GetTicks) to ensure smooth gameplay.
- A score of 8 – 8.5 reflects the completeness of features, effects, and overall player experience.
